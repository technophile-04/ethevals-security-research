# Multi-issue security candidates

Work in progress. Six candidates cover governance, staking, auctions, messaging, and account paths. Each candidate will include three separate issues and one local Foundry proof per issue.

The named `agent-registries` folder currently uses a fixed-answer check and contains no hand cases. I read ADR 0016 and used `governance-arbitrum-block-clock/tests/` for the current judge and hand-case format.

Harmless style advice passes when the reply names every required issue. A false vulnerability claim fails. A hedge between the right cause and a conflicting cause fails.

No model trials or paid judge calls are part of this draft. Confidence estimates remain unmeasured.
